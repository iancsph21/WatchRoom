WATCH TALIM - OPTIONAL WINDOWS COMPANION

You do NOT need this for browser screen sharing or watching.
Install it only to let an approved friend control your PC.

1. Install Python 3.12 or newer from https://www.python.org/downloads/windows/
   Include the Python launcher (py) and Tkinter.
2. Extract this ZIP into a folder.
3. Run Start-Companion.cmd. It installs the two required Python libraries.
4. In your TALWATCH room, expand Optional: let friends control your PC.
5. Download the companion pairing file.
6. In the companion choose Open host file, select it, and approve sharing.

The companion shares your entire primary monitor. Each control request needs
your approval. Press F8 at any time to stop sharing and control.
During control, your friend sees the companion's primary-monitor preview,
not the browser tab stream, so click coordinates match your PC.

Host files expire after 2 minutes. Download another if yours expires.
Never send your host file to someone else.
